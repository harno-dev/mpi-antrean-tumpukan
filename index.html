1. Struktur Data List (Daftar Berurutan)

Mutabel & Indeks Berbasis 0

List adalah struktur data linear dasar dalam pemrograman yang menyimpan kumpulan elemen data secara berurutan (*ordered sequence*). Setiap elemen di dalam List menempati lokasi alamat memori relatif yang diidentifikasi oleh angka unik yang disebut indeks (index).

Sifat utama dari List dalam bahasa pemrograman Python adalah Mutabel (Mutable), yang berarti isi elemennya dapat ditambah, diubah, disisipkan, atau dihapus kapan saja tanpa mengubah identitas objek wadah itu sendiri.

Diagram Pengindeksan Dua Arah dalam Python:

List Nama Siswa
Indeks [0]
"Andi"
Indeks [-3]
Indeks [1]
"Budi"
Indeks [-2]
Indeks [2]
"Cici"
Indeks [-1]

* Catatan: Indeks positif diakses dari depan (dimulai dari 0), sedangkan indeks negatif diakses dari paling belakang (dimulai dari -1).

Operasi-Operasi Utama Pada List (Sintaks Python TP 3.2):
append(x)

Menambahkan elemen x ke urutan paling akhir.

siswa.append("Dedi")
insert(i, x)

Menyisipkan elemen x secara presisi pada posisi indeks i.

siswa.insert(1, "Eka")
pop(i)

Mengambil & menghapus elemen pada posisi indeks i (Default: indeks terakhir).

s = siswa.pop(0)
remove(x)

Menghapus kemunculan pertama elemen bernilai x.

siswa.remove("Budi")
len(list)

Menghitung jumlah total elemen yang tersimpan di dalam List.

total = len(siswa)
Slicing List

Mengambil sub-bagian elemen dari indeks awal hingga sebelum indeks akhir.

sub = siswa[0:2]

2. Tumpukan (Stack - Prinsip LIFO)

Last-In, First-Out

Stack (Tumpukan) adalah jenis struktur data linear terbatas (*restricted data structure*) tempat penambahan dan penghapusan elemen hanya diperbolehkan melalui satu pintu gerbang yang sama yang disebut Puncak Tumpukan (TOP).

Aturan akses utamanya adalah LIFO (Last In, First Out) — artinya, data yang paling akhir dimasukkan akan berada paling atas dan menjadi data yang pertama kali dikeluarkan.

Anatomi Struktur Stack
Eksperimen 1 (Dasar)
Eksperimen 2
Eksperimen 3 (TOP / POP)
⬅️ Hanya Terbuka di Puncak (TOP)
PUSH (Menumpuk Data)

Menambahkan elemen baru ke paling atas tumpukan.

stack.append("Data Baru")
POP (Mengambil Data)

Mengambil & menghapus elemen yang berada di paling atas tumpukan.

elemen_top = stack.pop()
PEEK / TOP (Melihat Data)

Melihat nilai elemen teratas tanpa menghapusnya dari tumpukan.

top_val = stack[-1]
Penerapan Konsep Stack dalam Aplikasi Komputer:
  • Fitur Undo / Redo: Ketika menekan Ctrl + Z di MS Word atau Photoshop, aksi perintah paling akhir dicabut pertama kali.
  • Tombol Back pada Web Browser: Riwayat halaman web yang kamu kunjungi ditumpuk; menekan tombol *Back* akan kembali ke URL terakhir.
  • Call Stack Pemanggilan Fungsi: Kompiler bahasa pemrograman menyimpan urutan pemanggilan fungsi dalam memori tumpukan eksekusi.

3. Antrian (Queue - Prinsip FIFO)

First-In, First-Out

Queue (Antrian) adalah struktur data linear dua pintu terpisah: elemen baru masuk dari posisi Belakang (REAR / TAIL), sedangkan elemen lama dikeluarkan dari posisi Depan (FRONT / HEAD).

Aturan akses utamanya adalah FIFO (First In, First Out) — artinya, data yang pertama kali masuk adalah data yang pertama kali dilayani & keluar.

Anatomi Alur Kerja Queue
KELUAR (FRONT) ⬅️
P1 (Dilayani)
P2
P3
⬅️ MASUK (REAR)
ENQUEUE (Masuk Antrian)

Menambahkan elemen baru ke paling belakang barisan (REAR).

queue.append("Pelanggan Baru")
DEQUEUE (Keluar Antrian)

Melayani & menghapus elemen dari posisi paling depan (FRONT).

dilayani = queue.pop(0)
Efisiensi Pemrograman Python (Modul collections.deque):

Secara teknis, menggunakan list.pop(0) memakan waktu rumit $O(n)$ karena Python harus menggeser seluruh posisi indeks elemen di belakangnya. Untuk struktur data Queue berkinerja tinggi $O(1)$, Python menyediakan kelas from collections import deque dengan fungsi deque.popleft()!

Ringkasan Matriks Perbedaan List, Stack, dan Queue

Kriteria Perbandingan List (Daftar) Stack (Tumpukan) Queue (Antrian)
Prinsip Kerja Utama Akses Bebas Berdasar Indeks LIFO (Last-In, First-Out) FIFO (First-In, First-Out)
Gerbang Akses Data Semua Posisi Indeks ($0 \dots n-1$) Satu Gerbang (Puncak / TOP) Dua Gerbang (FRONT & REAR)
Operasi Tambah Data append(), insert() PUSH (append) ENQUEUE (append)
Operasi Hapus Data pop(i), remove() POP (pop()) DEQUEUE (pop(0) / popleft)
Contoh Dunia Nyata Daftar Nilai Siswa, Playlist Musik Tumpukan Buku, Piring, Undo MS Word Antrean Kantin, Cetak Printer
